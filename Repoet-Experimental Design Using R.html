Introduction
A rigorous, hands-on guide to experimental design using R, built around two foundational pillars: error rate control across multiple comparisons and statistical power analysis. Each section blends theoretical derivation with live R simulation — from the Bonferroni correction formula to full Monte Carlo power curves — building genuine statistical literacy through code.

Topics Covered 12 Sections
⚖️
Bonferroni Correction
Controls FWER across k simultaneous tests. Plots α_Bonferroni vs. number of tests.
🔍
Influence Index Plot
Cook's D, leverage, Studentized residuals & DFFITS on Duncan prestige dataset.
📍
Outlier Test
Bonferroni-adjusted formal outlier detection via outlierTest() with manual verification.
📊
Post-hoc Power
Evaluates power of completed study. n=15, δ=1 → Power ≈ 75.3% (below 80% threshold).
🎯
A Priori Power
Plans required sample size before data collection. 80% power → minimum n=17 per group.
📈
Analytical Power Curve
Theoretical curve via power.t.test() across n=3–200. 80% power at n≈64 per group.
🎲
Single Simulation
One synthetic t-test illustrates Type II error even when true effect exists (p=0.116).
🔁
10,000 Simulations (n=20)
Empirical power ≈ 34.2% — 66% chance of missing the true effect at this sample size.
🔁
10,000 Simulations (n=40)
Doubling n raises empirical power to ≈60%. Type II error drops from 66% → 40%.
🔄
Nested Loop Power Curve
Full empirical power curve: outer loop over 198 sample sizes × 1,000 t-tests each.
⚡
Combined Power Curve
Analytical vs. simulation overlay. Near-perfect overlap validates Monte Carlo approach.
🔬
Sensitivity Analysis
Fixed n=20; power plotted by effect size. ~δ=1.8 needed for 80% power — min detectable effect.

Conclusion
This notebook delivers a complete toolkit for sound experimental reasoning. Beginning with the Bonferroni correction, learners see how false positive risk escalates with the number of tests — and how a simple threshold adjustment restores control. Regression diagnostics reveal that valid analysis requires vigilance about influential observations, not just correct model selection. The power analysis arc — from post-hoc evaluation to a priori planning, analytical curves, and full Monte Carlo pipelines — builds a mechanical understanding of what power means in practice. The near-perfect overlap of analytical and simulated power curves confirms that simulation is a valid, flexible tool for any design. The final sensitivity analysis answers the experimentalist's most practical question: given my resources, what is the smallest effect I can reliably detect?
